## 安裝和上手

想要使用 Codex APP，你只需要準備一個 ChatGPT 賬號。可以免費體驗，但是有條件的話最好開個 Plus 會員（每月 20 刀，約 150 元），額度更充裕，足夠日常使用了。

有了賬號，直接去官網下載安裝 Codex APP 就好：

> [https://chatgpt.com/zh-Hans-CN/codex/get-started/](https://chatgpt.com/zh-Hans-CN/codex/get-started/)

![](https://pic.yupi.icu/1/1779336698802-47791125-80cf-46b7-a0ca-c2bc4bb00af5.png)

目前支援 macOS 和 Windows（Linux 使用者可以使用命令列版本的 Codex CLI）。

下載並安裝後，登入你的 ChatGPT 賬號，開啟之後的介面長這樣：

![](https://pic.yupi.icu/1/1779152920233-5a0c20fa-63f1-469a-b1e6-267b825a7bc9.png)

左側是各種面板入口，包括對話管理、外掛、自動化等功能。中間就是對話方塊，你跟 AI 所有的互動都在這裡完成。

跟平時用的 AI 聊天工具差不多，還挺清爽的，不像傳統 IDE 那麼複雜，上手零門檻。

接下來我們直接開始用。



## 基本使用

### 直接開聊

安裝好之後，跟你用過的其他 AI 工具一樣，在對話方塊裡輸入內容傳送就能開始聊天了。

適合處理一些簡單的日常工作，比如幫你查資料、總結內容、規劃方案。

我讓它幫我查一下今天有什麼 AI 程式設計方面的熱點：

```plain
今天有哪些值得關注的 AI 程式設計熱點？
```

![](https://pic.yupi.icu/1/1779336915390-b2e65963-dfb7-491b-b8c2-41bd21c5713c.png)

Codex 會自動聯網搜尋最新資訊，然後幫忙整理總結，這下不怕錯過新資訊了。

![](https://pic.yupi.icu/1/1779153373327-27da7ef6-33bc-4458-a724-82983e7598af.png)

這只是開胃菜，Codex 真正強大的能力是操作你本地的檔案和電腦，下面我們試試。



### 檔案操作實戰 - 分析磁碟空間

點選左側的專案入口，選擇一個本地資料夾。你可以把它理解為給 AI 劃定了一個工作空間，AI 能在這個範圍內讀取和操作檔案。

![](https://pic.yupi.icu/1/1779336958427-e777e453-1322-422b-8ba2-410a46f98d88.png)

比如我選擇了我的下載資料夾，裡面有一堆不知道什麼時候存下來的大檔案。

在對話方塊底部，你可以看到許可權模式的選項。這裡有 3 個選擇：

+ 預設許可權：AI 可以讀取和編輯工作區的檔案，需要額外許可權時會問你
+ 自動審查：AI 自動幫你審查操作
+ 完全訪問：AI 想幹啥幹啥，不會彈確認框

新手建議直接選「自動審查」，既省時又省心。

![](https://pic.yupi.icu/1/1779155081273-d9dcf99b-2320-4324-b5ee-e92c60ef8089.png)

選好許可權後，在對話方塊裡輸入提示詞：

```plain
幫我分析這個資料夾的空間佔用情況
找出所有超過 500MB 的大檔案，逐個分析
最後按大小排序列出來，並給出清理建議
```

然後你就能看到 AI 開始工作了。它會自動執行終端命令來掃描檔案，分析每個檔案的名稱和大小。

![](https://pic.yupi.icu/1/1779154335788-c16d9c06-762e-4df0-a381-ba7a3b5f2ba2.png)

最後給你一份清晰的報告，列出哪些大檔案佔了多少空間，並給出清理建議。

![](https://pic.yupi.icu/1/1779154370922-133458f6-ccc7-4636-8c83-6e16ee65beaa.png)

我主打一個聽話，讓 AI 幫我刪除沒用的預覽檔案：

```plain
刪除預覽檔案
```

成功幫我節省了 6.8G 的空間，效果不錯吧~

![](https://pic.yupi.icu/1/1779155042790-7ff63ce3-6c1a-4233-8d0d-d441c35c1b94.png)

但如果我讓 AI 刪除一個工作區外的檔案呢？會發生什麼？

試試看，在當前工作空間，開啟一個新對話，比如我讓 AI：

```plain
幫我刪除「魚皮新書出版」目錄下的所有檔案
```

可以直接把這個目錄拖拽到對話方塊中，然後執行任務：

![](https://pic.yupi.icu/1/1779155842265-b3d48a0e-a1e8-4046-8e7f-b7fc1daf9035.png)

如果你選擇的許可權模式是「預設模式」，AI 想刪除檔案的時候會彈出一個確認框，問你同不同意，防止 AI 搞亂你的電腦。

![](https://pic.yupi.icu/1/1779337159740-50aeb939-b0c5-4b76-bf6b-53b6414a42c2.png)

但由於我選的是「自動稽核」，AI 自己完成了稽核並批准，省去了人工操作的麻煩。

![](https://pic.yupi.icu/1/1779155710161-9e06ac9e-a5ab-4f77-a6a6-2999edd8d01d.png)

這樣一來，你完全可以把 Codex 當成你的私人檔案管理助手，分析空間、清理垃圾、批次重新命名，以前要手動折騰半天的事情，現在一句話就搞定了，是不是挺方便的？



### 檢視使用情況

做完第一個任務，大家肯定很關心消耗了多少 tokens 吧？

來，一起看看用了多少額度。

點選左下角的「設定」，點選「剩餘額度」，就能看到你 5 小時內還剩多少配額、本週還剩多少比例，什麼時候重新整理。

Codex 的額度按 5 小時和 1 周來限制，Plus 使用者的額度還是比較大方的，日常使用完全夠。

![](https://pic.yupi.icu/1/1779156041540-ef8bd8a6-6845-4cfc-9f75-12a7016acca1.png)

你也可以在對話方塊裡輸入 `/狀態`，這種以 `/` 開頭的快捷輸入叫做「斜槓命令」，是 Codex 內建的快捷操作方式：

![](https://pic.yupi.icu/1/1779337298452-0038dc21-660d-44d1-b703-751c6b45c5b0.png)

輸入之後，Codex 會直接在對話中顯示當前的上下文餘量和額度資訊。

![](https://pic.yupi.icu/1/1779156287183-1ac8ff57-5bd1-4bd9-b9f7-6f409a494b9a.png)

OK，到這裡你已經體驗了 Codex 最基礎的能力：對話 + 操作本地檔案。恭喜，已經超過了 60% 的同學！

## AI Agent 程式設計實戰

在開始之前，先進入設定，把工作模式從「適用於日常工作」切換為「適用於程式設計」，這樣 AI 的回覆會更專業、更適合開發場景。

![](https://pic.yupi.icu/1/1779156674435-205820a6-e9ec-4b65-b4cc-17850363f1b1.png)



### 專案介紹

我要用 Codex 來為自己定製一個專屬的「電子名片」。

把資訊告訴 AI，它幫忙生成一個精美的網站。

還能用 AI 生圖能力生成個性化的頭像插畫，不用自己去找素材。

做完之後發給別人，他們開啟連結就能看到你的資訊了。



### 第一步、計劃模式，先討論再動手

新建一個專案資料夾（比如叫 `namecard`），在 Codex 中開啟。

模型選擇目前最新的 GPT-5.5，速度選「標準」就夠了，智慧程度選「高」。

許可權我直接給了完全訪問，省得它每次操作都來找我確認，反正大部分情況下我都是無腦點同意的。

最關鍵的是，點選對話方塊左下角的 + 號，把「計劃模式」開啟。計劃模式下，AI 不會直接開始寫程式碼，而是先幫你規劃方案、問你細節，確認沒問題了再動手。

![](https://pic.yupi.icu/1/1779337693857-b6262b5e-24b4-433b-a561-a74109ba1538.png)

輸入下面這段提示詞，啟動！

```plain
幫我生成個人電子名片網站，以下是我的資訊：

- 姓名：程式設計師魚皮
- 職業：程式設計師 / AI 程式設計博主
- 簡介：前騰訊全棧開發，現自主創業，帶團隊開發了程式設計導航、面試鴨、魚皮 AI 導航等產品
- 聯絡方式：GitHub: liyupi，網站: codefather.cn

要求：
1. 幫我生成一張卡通風格的程式設計師頭像插畫
2. 提供多種風格主題可切換
3. 響應式佈局，手機也能正常顯示
4. 介面要有設計感，參考蘋果官網的簡潔風格
```

AI 會先自己思考，然後可能會追問你一些細節，在彈出的問題面板中選擇就好。

![](https://pic.yupi.icu/1/1779337728296-e6664038-38a6-4080-89e9-41ca32f0142f.png)

最後會生成一份實現計劃文件，包括簡介、核心要求、測試計劃等資訊。你做的網站越複雜，越要仔細閱讀這個文件。

![](https://pic.yupi.icu/1/1779337765733-ee4408ce-1556-41b4-954c-50a788f5faef.png)

## 核心功能詳解 - 常用功能

接下來我把 Codex 的功能分成「常用功能」和「進階功能」兩大塊來講。

常用功能是日常會高頻使用的，進階功能則是有點兒門檻、但掌握後能讓你效率翻倍的。



### 4.1 外掛系統

在左側的「外掛」面板裡，你能看到 Codex 的外掛市場。

Codex 內建了不少精選外掛，比如 Computer Use 操控電腦、Chrome 操控瀏覽器、Spreadsheets 表格處理、Presentations 簡報，這些是 OpenAI 官方提供的核心能力。此外還有大量程式設計類和工具類外掛，涵蓋網站部署、遊戲開發、對接 GitHub 等各種場景，你可以在外掛市場裡按需搜尋和安裝。

![](https://pic.yupi.icu/1/1779338815978-86c15272-68ef-4c2a-b32d-750c4d571e76.png)

同樣的，如果你要處理 Excel 表格、做 PPT，使用對應的外掛讓 AI 幫你就好，生成的檔案還能在側邊欄直接預覽：

![](https://pic.yupi.icu/1/1779167724815-b34911a2-dbcf-4528-bedb-565afea3366e.png)



### 4.2 Browser Use

前面我們用的內建瀏覽器可以預覽頁面、做批註和修改，但如果想讓 AI 真正去操控瀏覽器、自動點選、填表單、翻頁，就需要 Browser Use 瀏覽器操作功能了。

#### 使用 Browser Use

進入設定 → 瀏覽器，確保 Browser Use 功能已開啟。你還可以在這裡設定許可權規則和禁止開啟的域名：

![](https://pic.yupi.icu/1/1779168154072-7593cee1-a276-466b-81ff-4b0202ed0d5e.png)

在對話中透過 `@瀏覽器` 來呼叫這個能力。比如我讓 AI 幫我開啟一個網站並截圖：

```plain
@瀏覽器 幫我開啟魚皮的面試刷題網站 mianshiya.com，找到 AI 相關的面試題庫並截圖
```

可以看到 AI 開啟了瀏覽器，從主頁找到了 AI 大模型面試題庫，然後進入了詳情頁，成功完成了截圖。不過有時候操作不太穩定，多試幾次就好。

![](https://pic.yupi.icu/1/1779169237030-18755502-058d-4861-bd31-3969f676fe24.png)



#### 使用 Chrome 擴充套件

此外，你還可以安裝 Codex 的 Chrome 擴充套件外掛，它可以操控你電腦上已經登入的 Chrome 瀏覽器。好處是能保留你的登入狀態，而且可以在後臺執行不佔螢幕。適合需要登入網站才能進行的操作，比如幫我在自己的後臺批次分析和管理資料。

![](https://pic.yupi.icu/1/1779338928043-8e41c68a-2804-454b-b2e2-f1c049241cc9.png)

使用前需要先在你的 Chrome 瀏覽器中安裝 Codex 擴充套件程式，跟著 Codex 的指引操作就好：

![](https://pic.yupi.icu/1/1779338943272-88b5dacd-d327-4186-8fb8-4a0b6dac725e.png)

安裝好之後，我讓 AI 幫忙從我已經登入的面試鴨網站上抓取一些資料：

```plain
@Chrome 獲取我在面試鴨 mianshiya.com 最新收藏的 5 個題目資訊，並彙總成表格
```

可以看到 AI 不僅連線了我電腦上的 Chrome 瀏覽器，而且還識別到了我已經開啟的標籤頁，會控制這些標籤頁，跳轉到我的個人主頁並抓取最新的 5 條資料：

![](https://pic.yupi.icu/1/1779173500736-4229d5cf-2ddf-4591-883f-f726f9c6bc05.png)

最終抓取到的資料表格非常清晰，連結前面甚至還有圖示~

![](https://pic.yupi.icu/1/1779173575488-10ba1005-c669-4daf-9819-6e8f84eb9a06.png)



### 4.3 Computer Use

如果說 Browser Use 只能操控瀏覽器，那 Computer Use 就是讓 AI 操控你的整個電腦。AI 能看到你的螢幕內容、移動滑鼠、點選按鈕、打字，還能操作微信、飛書等任何桌面應用。

進入設定 → 電腦操控，安裝 Computer Use 外掛。

![](https://pic.yupi.icu/1/1779339032660-47d44b31-0d77-44db-a6e3-a46d134293fb.png)

你可以在這裡看到所有已連線的應用，比如前面裝的 Chrome 擴充套件，其實也屬於 Computer Use 體系的一部分。

![](https://pic.yupi.icu/1/1779339059599-1af0c3f4-cfc8-4645-9121-434cea03d662.png)

我們來體驗一下。用 `@電腦` 來呼叫，讓 AI 幫我看看當前的桌面桌布，然後生成一張類似風格的新桌布：

```plain
@電腦 檢視我電腦的桌面桌布，然後用 AI 生成一個相似風格的新桌布圖片
```

首次使用時系統會彈出許可權申請框，你需要授權 Codex 訪問螢幕、截圖等許可權，否則 AI 看不到你的螢幕、也沒法幫你點選操作。

![](https://pic.yupi.icu/1/1779339090756-2cee0eb4-121e-41b7-8651-958f7829b317.png)

效果不錯吧，生成了一張非常精美的新桌布，我覺得比原圖還好看。。。今晚可以做個好夢了~

![](https://pic.yupi.icu/1/1779239684229-98db0196-5c90-4ff3-a37b-1c9f0aebf850.png)

再來一個更實用的例子。讓 AI 幫我開啟備忘錄，記錄一條筆記，並從音樂軟體下載我最喜歡的一首歌，新增到筆記中。

```plain
@電腦 幫我開啟備忘錄，記一條筆記：
- 今天跟魚皮用 Codex 學了很多新東西
- 今天跟魚皮用 Codex 學了很多新東西
- 今天跟魚皮用 Codex 學了很多新東西
並從網易雲音樂下載我最喜歡的一首歌，新增到筆記中
全程自主完成，不需要找我確認
```

可以看到 AI 會開啟音樂 APP，有個小滑鼠點選了下載按鈕，成功下載了音樂檔案「只因你太美」：

![](https://pic.yupi.icu/1/1779339162708-796fa18d-eff8-4f2f-a635-9878832f1294.png)

然後 AI 開啟了備忘錄，寫入內容，並新增了音樂檔案，能夠順利播放。

![](https://pic.yupi.icu/1/1779339197968-9c7eebdc-6248-4635-9ab7-83f0e458f903.png)

雖然過程有些曲折，但還是完成了任務，而且全程由 AI 自己操作，以後我可以直接讓 AI 幫我寫有圖有文有音樂的筆記了。

但 Computer Use 目前只支援 macOS，而且缺點一大堆。不僅操作效率偏低，還很燒 tokens，剛才那個任務就用了近 8 萬的上下文空間！此外，有些軟體對 Agent 的支援度不高，AI 無法成功操控。

![](https://pic.yupi.icu/1/1779242213409-38d6bd55-2c15-4ec6-9a6f-12cf94ef5e34.png)

所以建議能用終端命令列和瀏覽器完成的操作，就不要用 Computer Use。



### 4.4 Skills 技能包

Skills 你可以理解為給 AI 提供的技能包，裝了某個技能後，AI 在遇到相關任務時就能自動按照這套方法來幹活，不用你每次都寫一大堆提示詞。而且技能是按需載入的，只有任務匹配時才會呼叫，不會浪費上下文空間。

![](https://pic.yupi.icu/1/03_Skills%25E6%258A%2580%25E8%2583%25BD%25E5%258C%2585%25E8%25AE%25B2%25E8%25A7%25A3_compressed_v3.png)

進入左側的「外掛」面板，切換到「技能」Tab 頁，在這裡能夠視覺化安裝和管理技能。

Codex 自帶了幾個內建的技能，比如 Image Gen 圖片生成、OpenAI Docs 查官方文件、Skill Installer 安裝社群技能、Skill Creator 建立新技能、Plugin Creator 建立外掛等。

![](https://pic.yupi.icu/1/1779339269256-7dc84656-58db-49a4-9565-0be9bbee4d59.png)

下面我先帶大家用用內建的圖片生成技能，然後安裝社群裡別人做的技能，最後再來自己建立一個技能。



#### 使用影象生成技能

先來看內建的 Image Gen 影象生成技能。

前面做電子名片的時候我們已經用它生成了卡通頭像。除了頭像之外，你還可以用它來做 UI 素材、海報、橫幅、表情包等等。

這裡我想生成一個有趣的圖片，讓魚皮直播賣魚皮，可以先到 [魚皮 AI 導航網站](https://ai.codefather.cn/) 上找到 AI 生圖的提示詞模板，然後複製提示詞模板。

![](https://pic.yupi.icu/1/1779256863725-8758468e-c5cb-499e-ba9e-86dbb6779594.png)

然後在 Codex 對話方塊中輸入 `$` 符號 + 技能名稱，可以快速呼叫技能。並且把提示詞模板、魚皮的照片都提供給 AI：

```markdown
$image-gen 生成這個人在直播帶貨，賣魚皮的圖片
提示詞風格參考：
@從魚皮AI導航拿到提示詞模板
```

![](https://pic.yupi.icu/1/1779341541512-91e6b748-ac6c-485c-bc24-1f5ba3dd7a69.png)

看看 AI 生成的圖片，你覺得怎麼樣？是不是夯爆了？

![](https://pic.yupi.icu/1/1779246213558-a5abaa62-025d-44c9-b1d8-002e697c7394.png)

不過圖片生成比普通對話消耗的額度更多，用的時候留意一下剩餘配額。



#### 使用社群技能

內建的技能數量有限，還有很多寶藏在社群裡。

比如我自己經常用的幾個技能：用於聯網搜尋的 Firecrawl、用於獲取最新技術文件的 Context7、用於美化前端頁面的 UI UX Pro Max 等等。

如果想了解更多優質的 AI 程式設計擴充套件，可以閱讀本教程程式設計工具板塊中的《優質 AI 程式設計擴充套件推薦》。

接下來我帶大家實際安裝一個社群技能，順便整個活兒，讓 AI 製作一個蘋果風格的快閃動畫影片。

首先，要安裝動畫製作技能 remotion-best-practices。可以使用 `skill-installer` 技能，它能幫我們快速安裝其他技能。

對了，安裝社群技能時 **要注意安全**，由於我這裡安裝的是知名技能，就直接輸入技能名稱讓 Codex 幫我安裝了。如果你想安裝不太知名的技能，更穩妥的方式是把技能的 GitHub 連結發給 Codex，讓它幫你檢查後再精準安裝。

![](https://pic.yupi.icu/1/1779243952957-3c4a8be0-183b-4061-b6b7-20563da1120b.png)

安裝完成後，在技能管理面板裡就能看到新增的技能了：

![](https://pic.yupi.icu/1/1779243928649-af4d8522-23e7-423e-a5e9-76aee8e32e75.png)

然後我們使用技能，讓 AI 製作動畫：

```markdown
$remotion-best-practices 幫我製作一個蘋果風格的快閃動畫
文案：幫我舔著個老臉找觀眾要點讚的故事
搭配有節奏感的純音 BGM
最終直接給我提供影片檔案，必須自主完成任務
```

AI 會安裝製作動畫所需的專案和依賴包，然後生成影片和音訊，還會渲染單幀，檢查畫面有沒有問題：

![](https://pic.yupi.icu/1/1779244729111-af9516f7-1905-441a-a4a4-c803286dc7ba.png)



最後 AI 生成了可直接播放的影片，來看看效果：

![](https://pic.yupi.icu/1/1779244984051-766cfb16-07be-4325-a8c4-85625565b028.png)

額，他好像理解錯了我文案的意思哈哈，翻車了翻車了。。。

我感覺這種方式更適合做產品釋出宣傳片、知識點快閃卡、節日祝福影片這類節奏緊湊的短片。

而且我根本沒認真寫提示詞好吧！

你可以指定時長、指定文案、利用生圖技能搭配素材，增加更多互動動畫等等，感興趣的同學自己玩一玩。



#### 建立自己的技能

除了用別人的技能，你還可以把自己常用的工作流程封裝成技能，以後遇到類似任務一鍵複用。

技能的本質就是一個 `SKILL.md` 描述檔案，加上一些配套的指令碼和參考資料。`SKILL.md` 裡要寫清楚這個技能是做什麼的、什麼時候觸發、具體執行步驟，AI 讀取後就知道該怎麼幹活。

![](https://pic.yupi.icu/1/04_SKILL.md%2525E6%25258A%252580%2525E8%252583%2525BD%2525E6%252596%252587%2525E4%2525BB%2525B6%2525E7%2525BB%252593%2525E6%25259E%252584_compressed_v2.png)

建立技能的最佳方式是，先把一個任務流程跑通一遍，覺得滿意之後，使用內建的 `$skill-creator` 技能，告訴 Codex 你的技能要做什麼、什麼時候觸發、有什麼細節需要注意，它就會幫你自動生成完整的技能檔案。

實操一下，比如我們前面讓 AI 生成了直播帶貨的圖片，效果還不錯，那就把這個流程封裝成一個「直播帶貨圖片技能」：

```markdown
$skill-creator 幫我把上述工作封裝為「直播帶貨圖片生成技能」
互動式引導使用者輸入資訊，並生成圖片
```

執行成功後，AI 不僅建立了技能檔案，還貼心地教你怎麼呼叫：

![](https://pic.yupi.icu/1/1779247223043-2cb6ab77-abdd-4887-9b72-d18d29c8557f.png)

之後，使用這個技能，只需要提供一張人物照或者商品照，不用再自己填寫又臭又長的提示詞模板了，非常方便~

![](https://pic.yupi.icu/1/1779247820484-3bd99c02-379e-4830-9315-26973089c816.png)

看看效果，AI 自己識別到我提供的是商品圖，也是精準復刻我之前提供的提示詞模板：

![](https://pic.yupi.icu/1/1779247711750-d32da325-705e-4d40-ac95-f48fc80b170d.png)



### 4.5 MCP 連線外部服務

MCP（Model Context Protocol）是一個開放協議，你可以把它理解為 AI 的萬能插頭，裝上之後就能讓 AI 連線各種外部工具和資料來源，獲取實時資訊。

![](https://pic.yupi.icu/1/05_MCP%25E6%25A6%2582%25E5%25BF%25B5%25E7%25A4%25BA%25E6%2584%258F_compressed_v1.png)

進入設定 → MCP 伺服器，可以在這裡新增和管理 MCP 服務。

點選「新增伺服器」後，你需要手動填寫伺服器的配置引數才能完成新增，對新手不太友好，我最討厭填表單了！

![](https://pic.yupi.icu/1/1779341902401-d81e9164-6408-4de5-beea-fb10ee8e33cd.png)

好在大部分時候，用前面講的 Skills 就能解決 MCP 能做的事情，而且 Skills 的安裝和使用體驗更好。

此外，很多主流的擴充套件都提供了快捷安裝 MCP 的命令，不用你自己手動填引數。

比如我帶大家安裝 Context7，它是一個可以實時獲取最新技術文件的服務，開發網站的時候用它來查 API 文件特別方便。

![](https://pic.yupi.icu/1/1779341983443-9e49280a-f971-4851-885f-74a25c4c490b.png)

在 Codex 右上角可以開啟整合終端，在終端裡輸入一行命令就能安裝：

```bash
npx ctx7 setup
```

選擇安裝 MCP server、為 Codex 安裝，就搞定了。

![](https://pic.yupi.icu/1/1779249084658-19b46aa1-3c93-4db2-a6e6-530f78a7477a.png)

安裝後重啟 Codex，在設定裡的 MCP 伺服器列表中能看到它。首次使用前，還需要進行身份驗證，

![](https://pic.yupi.icu/1/1779249275289-1d9c97b0-f6e8-4bdb-b5ee-595e551631a6.png)

在自動彈出的 Context7 網頁中登入，然後同意授權。

![](https://pic.yupi.icu/1/1779342015467-a2244093-f071-4055-b412-89af0e451289.png)

授權成功後，就可以愉快地使用 MCP 了：

![](https://pic.yupi.icu/1/1779238127086-5db75a13-e967-420d-81f1-5afcf0abbb9b.png)

之後開發網站，尤其是需要整合 AI 能力的網站，都可以用 Context7 來獲取最新的技術文件。你還可以把它當成一個學習輔助，讓 AI 基於官方文件幫你講解知識。

比如我用它來做 OpenClaw 小龍蝦的學習助手，這也是利用 AI 學習的一種方式：

```markdown
$context7-mcp 你是我的 OpenClaw 學習助手
幫我獲取最新文件並理解，之後能快速回答我的問題
```

可以看到，AI 查詢並獲取到了 OpenClaw 官方最新文件庫：

![](https://pic.yupi.icu/1/1779249752304-161a453b-2fa2-4a13-8cf7-09d7dad37f72.png)

然後我們來問 AI 一個問題：

```markdown
OpenClaw 無法執行，怎麼辦？
```

AI 基於官方文件很快給出了精準的排障步驟，這樣學習和解決問題又快又準，再也不怕查到過時的資料了。

![](https://pic.yupi.icu/1/1779249770355-14771b85-f8a8-4d20-818f-7607b097099c.png)



恭喜，看到這裡你超過了 80% 的同學！

到目前為止，你已經掌握了 Codex 的常用功能，學到了不少實用玩法。從檔案管理到網站開發、從瀏覽器操控到技能封裝，已經能用 Codex 大幅提升工作效率了。



## 核心功能詳解 - 進階功能

接下來要講的是一些稍有門檻、或者不是每個人都用得上的進階功能。不過如果你願意多折騰一下，它們會讓你使用 Codex 的效率再上一個臺階。



### 4.6 上下文和對話管理
在對話區域附近有一個小圓圈，滑鼠放上去後，會實時顯示當前對話已經用了多少上下文。

![](https://pic.yupi.icu/1/1779342193484-1c7412d2-bf9e-4208-8c9c-87a02ac15202.png)

GPT-5.5 官方公佈的總上下文視窗是 400K tokens，但其中 128K 是留給輸出的，剩下 272K 輸入部分再乘以 95% 的安全係數，最終在 Codex 裡顯示的有效上下文約為 258K tokens。

說實話 258K 不算多，如果你連續跟 AI 對話很長時間、或者專案檔案比較大，上下文很容易被填滿。

當上下文快滿的時候，Codex 會自動幫你壓縮歷史對話。你也可以在任務告一段落時，手動輸入 `/壓縮` 來主動壓縮，讓模型更聚焦在新任務上。

![](https://pic.yupi.icu/1/1779330184279-ad15deb4-d042-4f56-a540-2c0f3db1e388.png)

除了單個對話的上下文，日常使用中還要注意管理對話本身，不然列表越來越長，找起來也費勁。

對話太多的時候，你可以在左側的對話列表中，把滑鼠放到對話上，點選「歸檔」，把不常用的舊對話歸檔起來，保持介面清爽。

![](https://pic.yupi.icu/1/1779330120439-c2fbfda4-c46a-4e97-8217-abda32f8833a.png)

進入設定 → 已歸檔對話，可以檢視和管理所有歸檔的對話記錄。

![](https://pic.yupi.icu/1/1779330061448-51d0acb9-526a-401d-88b8-394f8a7ac6f7.png)

另外建議在常規設定裡開啟「執行時防止系統休眠」，這樣跑長任務的時候電腦不會突然睡著，導致任務失敗。

![](https://pic.yupi.icu/1/1779342248884-57ce802e-df80-4271-a00c-3741b1cd3c7e.png)



### 4.7 持久記憶系統
Codex 有一套記憶機制，能讓 AI 記住你的偏好和專案規則，不用每次都重複交代。

記憶分為三個層級，從全域性、專案區域性、再到自動記憶，我們一個個來看。



#### 1、全域性自定義指令

在設定 → 個性化裡，可以修改 Codex 的個性和自定義指令。

你寫在這裡的內容，所有專案的所有對話都會自動帶上。適合記錄一些通用偏好，比如「回覆用中文」、「程式碼註釋用英文」之類的。

![](https://pic.yupi.icu/1/1779331122839-9ae33979-6151-4330-bb2f-7a46839ebfbb.png)

儲存之後，它會被寫入全域性的 `~/.codex/AGENTS.md` 檔案，這個檔案就是 Codex 每次啟動時都會讀取的「行為準則」，所有專案通用。

![](https://pic.yupi.icu/1/1779331195778-87290744-b084-4d4d-beb7-4a8073826635.png)



#### 2、專案級 AGENTS.md

在專案根目錄下建立一個叫 `AGENTS.md` 的檔案，寫入這個專案專屬的規則和約定。只有在這個專案裡工作時才會生效。

![](https://pic.yupi.icu/1/1779342300470-f44b0648-915a-4df0-8866-e9511862722d.png)

你可以自己手寫，也可以讓 Codex 根據專案情況幫你生成一份，比如跟它說：幫我根據當前專案寫一份 AGENTS.md。

可以看到 AI 生成了一份非常詳細的 AGENTS.md 文件，包括專案總覽、一些規範等等。

![](https://pic.yupi.icu/1/1779331059529-5985a98b-734e-4324-8617-6caa03d4b815.png)



#### 3、自動記憶

在設定 → 個性化中手動開啟自動記憶。

開啟後，AI 會在對話空閒一段時間後，自動在後臺總結出有用的資訊存為記憶，後續遇到相關場景時會自動召回，讓 AI 越用越懂你。

![](https://pic.yupi.icu/1/1779331262794-052e52b5-ed9c-4630-953c-a20a90a43629.png)

不過太短的對話它不會記，額度快用完的時候也不會觸發記憶生成。



### 4.8 定時自動化
Codex 支援定時任務功能。

進入左側的「自動化」面板，你能看到 Codex 已經內建了一些定時任務模板，不過基本都是和程式設計相關的，什麼總結程式碼變更、檢查程式碼問題之類的，很多人估計用不上。我們不妨來自己新建一個更實用的自動化任務。

![](https://pic.yupi.icu/1/1779342339487-c3e44a10-f14c-4d56-aa29-6c34d0a732f5.png)

建立定時任務的方式有 2 種。



#### 1、手動建立任務

一種是在自動化面板裡點「新建」，比如我讓 AI 幫我搜集每日熱點，需要填寫任務名稱、提示詞（幫你做什麼）、觸發時間、模型、推理程度。

執行環境選「本地」就好，意思是讓 AI 直接在你當前電腦上執行任務，不需要額外隔離的工作環境。

```markdown
標題：每日熱點搜尋
提示詞：從國內外蒐集今日 AI 相關熱點，整理成 HTML 結構的報告
```

![](https://pic.yupi.icu/1/1779342400695-dd591098-4926-41ee-8cc4-966ec17e5dd6.png)

建立成功後，時間一到 Codex 就會自動開啟一個對話來執行任務，我們也可以先手動執行一次看看效果。

![](https://pic.yupi.icu/1/1779327739060-7dcbe0b5-0671-4a3a-95d9-7110dde594b5.png)

點選任務，能夠檢視詳細資訊：

![](https://pic.yupi.icu/1/1779327610752-f322467e-2498-48c2-9ca0-09ee5534720b.png)

點選某個執行歷史記錄後，還能檢視正在執行的任務對話，建議多觀察任務的表現，持續迭代最佳化提示詞：

![](https://pic.yupi.icu/1/1779327672984-5d151560-bc4b-4143-b9f1-02e7f3b00b78.png)



#### 2、讓 AI 建立任務

另一種更自然的方式是，直接在對話裡跟 Codex 說，讓 AI 幫你建立任務。

比如我是一名內容創作者，每天都要截大量的圖片，時間一長，資料夾裡全是看不懂的檔名，找圖的時候巨痛苦。

![](https://pic.yupi.icu/1/1779328180129-64702cf8-d0c1-48a8-9ce9-8983164919bc.png)

所以我讓 Codex 幫我自動整理，先選擇專案，然後輸入提示詞：

```plain
幫我建立一個自動化任務
每小時掃描一次「魚皮的圖片庫」中最近 3 小時的圖片檔案
並根據圖片內容自動完善圖片的中文名稱
```

很快，AI 就自動幫你建好了，可以點選檢視建立出來的任務資訊，它的提示詞比我們提供的更完善了，並自動選擇了模型。

![](https://pic.yupi.icu/1/1779342459042-ee4814b3-80d9-43a8-9e66-349c75755193.png)

我們手動執行任務來測試一下，效果還不錯吧，AI 會根據圖片內容，自動給檔案起一個能看懂的名字。

![](https://pic.yupi.icu/1/1779328685443-8a79452f-bca6-43a7-aa29-c498d28c9e2c.png)

這樣我就有了一個智慧的圖片管家，以後再也不用對著一堆亂七八糟的檔名抓瞎了。

而且每次執行完，AI 還會把執行記錄寫入一個 Memory 檔案，你隨時可以回看歷史執行情況，不用擔心出問題了卻發現不了。

![](https://pic.yupi.icu/1/1779328889015-16b748c8-6760-442f-8a51-ab9981597413.png)

你還可以結合 Skills 和外掛一起用，比如每週自動生成周報 PPT、每日整理自己的學習筆記並同步到 Notion、每週用 Firecrawl 抓取競品網站更新並生成分析報告等等。



### 4.9 桌面寵物

想不到吧，現在的 AI 工具已經卷到開始給使用者增加情緒價值了。

#### 1、使用內建寵物

進入設定 → 外觀，下拉到底部的「寵物」區域，你會看到 Codex 內建了一排畫素風的賽博寵物。

選一隻後點選喚醒，桌面上就會出現一個懸浮的小傢伙。

它不只是個裝飾品，寵物會實時反映 Codex 的工作狀態，比如 AI 在忙的時候它在幹活，等你輸入時安靜待機，任務完成了會衝你揮手。就像一個跨應用的靈動島，讓你不用切視窗就知道 AI 幹完沒。

然後我們回到 Codex 主頁，使用 `/寵物` 指令喚醒。我腦袋中已經響起那個熟悉的 BGM 了（噔），你聽到了麼？

你還可以透過 Codex 內建的 `$hatch-pet` 技能自定義生成寵物，上傳照片或者文字描述都行。

比如我把自己的頭做成寵物。AI 會先分析上傳的圖片，給寵物起個名字。

### 4.10 程式碼審查和版本管理

每次 AI 修改了檔案，你都可以在側邊欄的「稽核」面板裡看到它改了什麼。

這個面板會列出所有被改動的檔案，展開能看到具體增加了哪些內容、刪除了哪些內容。

![](https://pic.yupi.icu/1/1779342665723-38604f09-7083-4b41-b07b-7a1d3f5bd5d3.png)



#### 應用和撤銷修改

如果你想決定哪些程式碼要保留，可以選擇檢視「未暫存」的檔案，在這裡你可以靈活應用和撤銷修改。

大多數情況下，你不需要自己看程式碼，直接點選「暫存全部」就行，相當於認可了本次全部改動；如果不滿意，可以直接「還原全部」，回到本次改動前的狀態。

![](https://pic.yupi.icu/1/1779342718411-5b5a64e8-b427-4419-9248-871f6f52b576.png)

如果你不滿意某個檔案的改動，直接點旁邊的「還原」按鈕就能恢復原樣；滿意的話點「暫存」就能標記為待提交。

你也可以只保留部分改動。每個檔案的改動會被自動拆分成多個程式碼塊，每個程式碼塊旁邊都有獨立的「暫存」和「還原」按鈕，你可以逐塊決定哪些保留、哪些丟棄。

![](https://pic.yupi.icu/1/1779342772594-12e61247-6a35-4fd8-b445-44439c648429.png)

確定好哪些程式碼要暫存之後，可以「提交」暫存的改動。提交就相當於給程式碼存了個檔，確認這次的修改是你想要的。

Codex 還內建了提交程式碼、推送到遠端倉庫、建立 Pull Request 的能力，不用離開 APP 就能完成整個程式碼管理流程，非常方便。

![](https://pic.yupi.icu/1/1779334288424-a3fa5040-f04a-49c1-a850-14563842808c.png)



#### 工作樹

如果你是專業的開發者，可以試試「工作樹」模式。你可以在建立新對話時選擇啟動模式為「新工作樹」：

![](https://pic.yupi.icu/1/1779334724648-9782f94d-4251-4c76-929d-f790a527bc1f.png)

這樣 AI 會在一個隔離的分支中工作，不影響你當前的程式碼。很適合同時讓多個 Agent 在同一個專案上並行幹活，減少衝突。

![](https://pic.yupi.icu/1/1779342810035-7655b92c-b28c-4f46-b7e9-0ef2be302cd7.png)



#### GitHub 外掛

如果你的專案託管在 GitHub 上，建議安裝 GitHub 外掛，可以直接在 Codex 裡檢視倉庫資訊、建立 Pull Request、做程式碼審查等等。

比如我讓它幫我查一下自己最受歡迎的開源專案：

```markdown
@GitHub 幫我檢視自己公開的 Star 數最多的前 10 個專案
```

![](https://pic.yupi.icu/1/1779334500107-206d8b6f-0148-4022-b42e-6f2246ee0d13.png)



### 4.11 手機遠端操控

Codex 最近新上線了一個很酷的功能，用手機控制電腦上的 Codex APP 幹活。

設定方法很簡單，在電腦端 Codex 點選「設定 Codex 移動版」，然後點選開始設定，螢幕上會顯示一個二維碼。

![](https://pic.yupi.icu/1/image-20260521155520575.png)

然後在手機上開啟 ChatGPT App（確保更新到最新版），掃描這個二維碼，在 ChatGPT 中確認賬號和工作區，完成可能需要的多因素認證步驟，就連線成功了。

連上之後，你可以隨時隨地透過手機給電腦上的 Codex 下達任務、審批 AI 的操作請求、檢視執行進度、檢查生成的程式碼和結果。你的專案檔案、已安裝的外掛和技能、所有配置都在那臺電腦上，手機相當於一個遠端遙控器。有點 OpenClaw 小龍蝦內味兒了哈？

![](https://pic.yupi.icu/1/image-20260521160038646.png)

除了手機連線電腦，你還可以從另一臺 Codex App 裝置繼續未完成的工作。比如你在公司用桌上型電腦跑了個長任務，回家後在筆記本上開啟 Codex 就能接著看結果、繼續操作。

你可以在 Codex 的連線設定中管理已連線的裝置，比如斷開某個手機的連線、設定是否保持電腦喚醒等等。

![](https://pic.yupi.icu/1/image-20260521155638870.png)

恭喜，看到這裡你超過了 90% 的同學！



## Codex 使用感受

學會了怎麼用 Codex 之後，我也分享一下自己使用 Codex 的感受吧。

Codex 適合零基礎或者不想折騰 IDE 和命令列的同學，下載就能用，使用門檻很低。尤其適合已經是 ChatGPT 付費使用者的人，不用額外花錢就能擁有一個全能 AI 助理。

我個人非常推薦大家體驗一下，尤其是非程式設計師，這可能是目前最適合你的 AI 程式設計工具。

但對我來說，目前 Codex 還不能完全滿足我日常 AI 程式設計的所有需求。

作為一名程式設計師和 AI 程式設計博主，我需要閱讀和審查程式碼、精細控制某一行改動、隨時切換不同的 AI 模型來對比效果，而這些 Codex 目前做得還不夠好，沒有內建程式碼編輯器、閱讀程式碼的體驗也一般。

所以實際使用的時候還是會搭配 VS Code 程式碼編輯器，或者很多工直接在 Cursor 裡搞定。

![](https://pic.yupi.icu/1/image-20260521162851912.png)

而且 Codex 的版本管理完全依賴 Git，專案必須是 Git 倉庫才行，新手有一定門檻。

切換模型不夠靈活，桌面端預設只有 OpenAI 自家模型，想用其他的得去改配置檔案或者用 CC Switch 之類的視覺化工具。

而且目前對我來說最致命的是，GPT-5.5 在 Codex APP 的訂閱模式下有效上下文只有 258K，做大型專案重構時跟其他 AI 程式設計工具和模型支援的 1M 上下文比，還是有差距。

不過每個工具都有自己的定位。Codex 更像一個什麼都能做的「AI 助理 APP」，門檻最低；Cursor 更像一個兼顧程式碼編輯體驗的「AI IDE」；Claude Code 更像終端裡推理能力最強的 AI 大腦。

這幾個工具的使用邏輯都差不多，學會一個再上手其他的會很快。如果想了解更多 AI 程式設計工具的對比和選擇建議，可以閱讀本教程程式設計工具板塊的《AI 程式碼編輯器》和《我的 AI 工具箱推薦》。
