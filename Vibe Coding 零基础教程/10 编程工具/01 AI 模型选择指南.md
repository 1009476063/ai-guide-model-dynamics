# AI 模型选择指南

你好，我是鱼皮。

我们已经了解了 AI 编程工具的 3 大类型。但无论你选择零代码平台、代码编辑器还是命令行工具，它们背后都有一个共同的核心 —— **AI 模型**。

你可能会好奇：

- Cursor 里可以选 Claude、ChatGPT、Gemini，它们到底有什么区别？
- 为什么有的人说 Claude 编程最强，有的人却更推荐 ChatGPT？
- 国产大模型靠谱吗？和国外的模型差距有多大？

别担心，这篇文章我会用最接地气的方式，带你搞懂主流 AI 模型的特点，教你如何根据自己的需求选择合适的模型。

需要提醒的是，AI 模型更新很快，这篇文章的内容是基于 2026 年 9 月下旬的情况。未来可能会有新的模型出现，或者现有模型的能力发生变化。所以要保持关注最新动态，灵活调整自己的选择。每次有重要的新模型发布，我都会在本教程模型动态板块中记录实测结果，可以配合着看。



## 一、什么是 AI 模型？

我们先来搞清楚一个基本概念：什么是 AI 模型？

简单来说，**AI 模型就是 Vibe Coding 工具背后的 “大脑”**。

当你在 AI 编程工具中输入需求时，是 AI 模型在理解你说的话；当你看到生成的代码时，也是 AI 模型写出来的。不同的 AI 模型就像不同领域的专家，各有所长。有的擅长写代码、有的擅长整理文献，有的速度快、有的质量高。

打个比方来说：

- AI 编程工具（Cursor、Bolt.new）= 工作台
- AI 模型（Claude、ChatGPT）= 坐在工作台前干活的程序员

所以，同样是用 Cursor，选择 Claude 和选择 ChatGPT，就像请了 2 个不同风格的程序员来帮你写代码，最终的效果自然会不一样。

## 二、主流 AI 模型

截止到 2026 年 9 月，市面上的 AI 模型已经非常丰富了。按照来源和定位，可以分为 3 大阵营：

- 国际顶尖模型：Claude、ChatGPT、Gemini 这三大巨头，以及主打性价比的 Grok
- 国产优秀模型：DeepSeek、智谱 GLM、通义千问、Kimi 等性价比之选
- 还有开源模型：Llama、Qwen 等，需要一定技术能力自己部署

对于我们学习 Vibe Coding 来说，主要关注前两类就够了。开源模型虽然灵活，但配置和使用门槛较高，不太适合新手。

![](https://pic.yupi.icu/1/image-20260106202328517.png)

接下来，我会逐一介绍这些主流模型的特点，帮你找到最适合自己的那一个。



## 三、Claude 最强编码能力

Claude 是 Anthropic 公司推出的 AI 模型系列，一直被公认为编程能力最强的 AI 模型。2026 年 Claude 的迭代节奏非常快，从年初的 Opus 4.6、Opus 4.8，到年中进入 5 代的 Fable 5、Opus 5、Sonnet 5，再到 9 月 1 日的 Fable 5.1。

而 2026 年 9 月 23 日（北京时间），Anthropic 又发布了 **Claude Opus 5.5**，开启了 5.5 家族。官方说它在大多数任务上都能打平自家最贵的 Fable 5.1，运行成本却比 Opus 5 低 40%。同系列的 Sonnet 5.5 和 Haiku 5.5，官方说会在几周后跟进。

截止到 2026 年 9 月下旬，Claude 的在售阵容是这样的：

| 模型 | 定位 | 价格（输入 / 输出，每百万 token） | 上下文 |
| --- | --- | --- | --- |
| Claude Opus 5.5 | 最新旗舰，长时间 Agent 编程和知识工作 | $4 / $20 | 1M |
| Claude Fable 5.1 | 高难推理和长周期智能体任务 | $10 / $50 | 1M |
| Claude Opus 5 | 上一代旗舰 | $5 / $25 | 1M |
| Claude Sonnet 5 | 速度和智能的最佳平衡 | $2 / $10 | 1M |
| Claude Haiku 4.5 | 最快的轻量模型 | $1 / $5 | 200K |

Opus 5.5 的单价比 Opus 5 降了 20%，缓存读取更是从每百万 token 0.5 美元降到了 0.2 美元。而 Agent 编程这类场景里，缓存读取才是成本大头。所以现在的选择思路很简单：**复杂任务直接从 Opus 5.5 开始，日常中等难度的任务用 Sonnet 5 更省**，Fable 5.1 的性价比已经被 Opus 5.5 比下去了。

不过「便宜 40%」这个说法要打个问号。第三方评测机构 Artificial Analysis 发现，Opus 5.5 开到最高推理档位时特别能想，每个任务的输出 token 比 Opus 5 多了六成多，算下来单任务成本跟 Opus 5 基本持平。官方说的省钱，主要是指默认的 medium 档位。另外对接 API 的同学要注意，Opus 5.5 的思考模式没法关闭，默认推理强度也从 high 降到了 medium。



### 为什么说 Claude 编程最强？

Claude 在代码理解、重构、调试等方面的表现都特别突出。它能准确理解复杂的代码逻辑，擅长优化和改进现有代码，能快速定位和修复 bug，而且上下文记忆好，不容易失忆。

经过这一年的迭代，Claude 全系已经标配了这些能力：100 万 token 上下文窗口、128K 输出 token、自适应思考（简单问题秒回，复杂问题慢慢想）、上下文压缩（长任务不会因为撞到上限而中断）、努力度控制（可以按需平衡质量和成本），以及在 Claude Code 中编排大量并行子 Agent 的动态工作流。

到了 Opus 5.5，官方跑分几乎全面领先：考察长程终端编程的 Terminal-Bench 4.0 拿了 66.4%，Fable 5.1 是 55.8%，GPT-6 Astra 是 57.9%；Artificial Analysis 的综合智能指数也冲到了第一。

我自己用 5 个案例让它和同一天发布的 GPT-6 Sol 正面对比，除了速度，Opus 5.5 每一项都赢了。3D 重庆城市生成器的细腻程度让我直接「卧槽」，复刻 Cursor 这道题更是我测过的所有模型里最像的一次。官方还特别强调它写东西更像人话，实测下来确实很有人味（可以阅读本教程模型动态板块中的《Claude Opus 5.5 双模型横评 - 对比 GPT-6 Sol 实测 5 个案例》）。

代价也很明显：慢，而且贵。那 5 个案例 Opus 5.5 前后跑了 3 个多小时，花了我 600 多块钱。如果你想看上一代的表现，可以阅读《Claude Opus 5 编程能力实测 - 7 个项目案例》和《Claude Fable 5.1 编程能力实测 - 3 个项目案例》。

这些优势让 Claude 特别适合需要高质量代码的开发者、做复杂项目的人、对代码质量要求高的场景。

**当然，前提是你的预算充足。**

## 四、ChatGPT 智能和速度兼具

说完了 Claude，我们再来看看 ChatGPT。

ChatGPT 是 OpenAI 公司的产品，也是最早让 AI 聊天火遍全球的工具。2025 年 OpenAI 推出了 GPT-5 系列，2026 年又先后发布了专攻编程的 GPT-5.3-Codex、支持 1M 上下文的 GPT-5.5，以及 GPT-5.6 的 Sol / Terra / Luna 三档。

到了 2026 年 9 月，OpenAI 进入了 GPT-6 时代，目前一共有 3 个档位：

- **GPT-6 Astra**（9 月 3 日发布）：旗舰模型，官方称它是「全世界最智能、也最对齐的模型」。它主打的不是写代码，而是 **像人一样操作电脑**：看屏幕、点按钮、填表单。屏幕理解跑分 ScreenSpot-Pro 从上一代的 76.9% 拉到了 92.7%，真实电脑干活的 OSWorld 完成率也从 65.7% 提升到 72.6%。
- **GPT-6 Sol**（9 月 23 日发布）：Astra 下面一档，主打复杂编程和 Agent 工作流，价格比 GPT-5.6 Sol 直接砍半。不过第三方综合智能指数只比上一代高了 1 分，更多是「便宜了」而不是「变强了」。
- **GPT-6 Luna**（和 Sol 同时发布）：轻量档，主打摘要、抽取、快问快答这类高并发任务，价格便宜到跟国产 Flash 模型差不多。

9 月 29 日，OpenAI 又推出了 **GPT-6.1 Sol**，性能接近 Astra、成本更低，现在是 Codex 里主推的编程模型。要注意的是，Sol 和 Luna 目前只在 ChatGPT Work 和 Codex 里能用，普通的聊天界面暂时用不了。另外老的 GPT-5.5 已经在 2026 年 10 月 14 日从 ChatGPT 和 Codex 里退役（API 还能继续调用），如果你的配置里还写着 `gpt-5.5`，记得换成新模型。

![](https://pic.yupi.icu/1/image-20260106221446611.png)

虽然在纯编程能力的比拼上，ChatGPT 稍微逊色于 Claude，但它有自己的独特优势。

首先是速度更快，生成代码的速度比 Claude 快不少，特别适合需要快速迭代的场景。其次是知识更新及时，对最新技术和框架的了解更快。而且生态更好，插件和工具支持更丰富，中文理解和生成能力也更强。

值得单独提一句的是 GPT 旗舰的前端审美终于翻身了。以前 GPT 做前端经常被吐槽土、爱偷懒，而 GPT-6 Astra 做出来的东西会自己设计品牌名、配色体系和产品细节（可以阅读本教程模型动态板块中的《GPT-6 Astra 编程能力实测 - 4 个项目案例》）。

不过 Astra 额度消耗太快了，Plus 账号跑一两个项目就能把 5 小时额度耗光。所以日常在 Codex 里干活，我更推荐 GPT-6 Sol：我用它跑完一整套 5 个案例的测试，刚好用完 Plus 会员的额度，速度比 Claude Opus 5.5 快好几倍。只是做出来的效果比较一般，跟国产模型差不多是同一档（可以阅读本教程模型动态板块中的《Claude Opus 5.5 双模型横评 - 对比 GPT-6 Sol 实测 5 个案例》）。

另外 OpenAI 在 2026 年 9 月还发布了新一代生图模型 **ChatGPT Images 2.5**，新增了手绘草图参考、图片标注精修、透明背景等能力，对做产品需要的 Logo、封面、宣传图很有用（可以阅读本教程模型动态板块中的《GPT Images 2.5 生图能力实测 - 10 个创意玩法》）。

所以，如果你需要快速原型开发、对速度要求高、或者需要 AI 帮你操作各种没有 API 的软件，ChatGPT 是不错的选择。

ChatGPT 的价格和获取方式：

- ChatGPT Plus：每月 20 美元
- ChatGPT Pro：每月 100 美元（5 倍用量）或每月 200 美元（20 倍用量）
- API 调用：按 Token 计费（每百万 token 输入 / 输出），GPT-6 Astra 为 $10 / $50，GPT-6 Sol 为 $2 / $10，GPT-6 Luna 为 $0.10 / $0.50

![](https://pic.yupi.icu/1/image-20260106203501181.png)

用 API 的话有个坑一定要知道：**GPT-6 系列的上下文窗口虽然有 105 万 token，但单次请求的输入一旦超过 27.2 万 token，整次请求的输入费率翻倍、输出费率涨 1.5 倍**。所以别看窗口大就往里猛塞，超过那条线账单是阶梯往上跳的。另外 Batch 和 Flex 是标准价的一半，追求低延迟的 Fast 模式是标准价的两倍。

要提醒的是，「全球最强」这个说法在 OpenAI 自己挑的那批跑分上成立，换成第三方评测机构 Artificial Analysis 的综合智能指数就未必了 —— 现在那份榜单的第一名已经是 Claude Opus 5.5。而且 Anthropic 和 OpenAI 这次都是拿对方的旧模型来对比，发布不到两小时对方的图就过时了。这也是看新模型发布时最该留意的一点：**厂商挑的跑分一定是自己占优的项目，第三方综合指数和实测才更接近日常体感**。



## 五、Gemini 高性价比的长上下文选手

接下来是 Gemini，Google 推出的 AI 模型。Gemini 3 系列有两条线：顶配的 Gemini 3 Pro 各方面能力都很全面，轻量的 Flash 线速度快、价格便宜。

![](https://pic.yupi.icu/1/image-20260106221514964.png)

Google 在 Flash 这条线上迭代得非常猛，2026 年 7 月到 9 月的六周里连发了 3.6、3.7、3.8 三个版本。最新的 **Gemini 3.8 Flash** 发布于 2026 年 9 月 2 日，模型 ID 是 `gemini-3.8-flash`，1M 上下文窗口，输出上限 64K。

Gemini 最厉害的地方是它的超长上下文窗口，Gemini 3 Pro 和 Flash 都支持 **1M Token**（约 100 万字）的输入上下文。

这意味着什么呢？

它可以一口气读完整个大型项目的所有代码，可以记住超长的对话历史、不会轻易失忆，可以同时分析大量的文档和资料。

而且在 UI 构建方面，Gemini 3 Pro 的表现也特别出色。根据实测，它在前端 UI 设计、3D 模型构建等方面的能力很强，在某些场景下甚至超过了 Claude 和 GPT-5。

![一句话开发 3D 动画网站](https://pic.yupi.icu/1/1763785739331-b643bd7d-85d6-42d9-8462-f842a8a790e6.png)

所以如果你需要处理大型项目、需要分析大量代码、做 UI / 前端开发、或者预算有限但需要强大能力，Gemini 会是很好的选择。

Gemini 的价格和获取方式：

- Gemini AI Pro 订阅：每月 19.99 刀
- API 调用：Gemini 3.8 Flash 为 $0.75/M 输入、$3.75/M 输出，比 Claude 和 GPT 便宜很多
- 免费版本：Flash 系列有一定的免费额度，每天也有几次思考模型的试用

这里必须提醒两件事。第一，**0.75 / 3.75 这个价格是引导价，只到 2026 年 12 月 31 日，2027 年 1 月 1 日起翻倍到 1.50 / 7.50**，做长期成本预算时一定要把这个时间点算进去。第二，Google 宣传 3.8 Flash 跟上一代「同价同速」，但第三方实测下来单任务消耗的 token 涨了将近 30%、实际成本涨了 40%，首字延迟也偏高（平均 13.3 秒，同类模型中位数只要 3 秒左右）。

我用 3 个项目实测过 Gemini 3.8 Flash，跑分虽然咬得很紧，但前端审美和 Claude 顶级模型差距明显，价格上相比国产模型也没什么优势（可以阅读本教程模型动态板块中的《Gemini 3.8 Flash 编程能力实测 - 3 个项目案例》）。

2026 年 10 月 13 日，Google 终于全面开放了时隔 7 个多月的新旗舰 **Gemini 4 Argon**。官方跑分表里跟 GPT-6 Astra、Claude Fable 5.1、Claude Opus 5.5 比了 19 项，Argon 拿了 14 项第一，但编程相关的 Terminal-bench 4.0 比 Opus 5.5 低了 9 个点。价格是每百万 token 输入 4 美元、输出 20 美元，11 月 30 日之前限时五折。我用 3 个项目实测下来，它完成速度快、3D 和美术能力进步明显，但前端细节粗糙，还会用调试接口「摆拍」自测结果，离能直接交付还有差距，用它一定要自己验收（可以阅读本教程模型动态板块中的《Gemini 4 Argon 编程能力实测 - 3 个项目案例》）。



## 六、Grok 同价升级的性价比选手

除了上面三巨头，xAI（现在叫 SpaceXAI）的 Grok 系列也值得了解一下。

2026 年 9 月 21 日发布的 **Grok 4.7** 是它目前最强的编程和办公模型。它换了一个更大的基座模型，但价格和速度跟上一代 Grok 4.6 保持一致，每百万 token 输入 2 美元、输出 6 美元，只有 Claude Fable 5.1 和 GPT-6 Astra 的零头。另外还有一个输出速度翻倍、价格也翻倍的 Fast 版本。

能力上，它在考察长程编程任务的 CursorBench 4.0 上拿了 46.3%，超过了 GPT-5.6 Sol，但离 Fable 5.1 的 51.8% 还有差距；在长程终端任务上跟 Claude 顶级模型的差距就更明显了。所以它的定位很清晰：**不追求最强，追求同价位里够强**。

Grok 4.7 发布当天就上线了 Cursor 和 GitHub Copilot，想试试的话直接在模型列表里切换就行。不过要注意，同价不等于同成本，有 Cursor 用户统计过，4.7 因为想得更多、用的 token 更多，单任务的平均花费是 4.6 的 2.5 倍左右。



## 七、国产大模型 - 性价比之选

### 主流国产模型有哪些？

说完了国际三巨头，我们再来看看国产大模型。如今，国产大模型在编程能力上已经追上来了，甚至在某些方面还超越了国际模型！

- DeepSeek 是开源模型，编程能力在国产模型中数一数二。截止到 2026 年 10 月，DeepSeek 的主力模型是 **DeepSeek V4.1 Flash**，552B 参数的 MoE 模型，采用全新模型结构，**原生支持多模态视觉理解**。它 9 月 10 日首发，10 月 17 日又更新到了 1017 版本，价格不变，3D 和前端能力却明显变强，任务耗时和费用还更低了（可以阅读本教程模型动态板块中的《DeepSeek V4.1 Flash 1017 编程能力实测 - 4 个项目案例》）。官方称它全面超越了上一代旗舰 V4 Pro，旧的 V4 Flash 模型已经下线，请求会自动路由到 V4.1 Flash；V4 Pro 原本也计划下线，后来应用户需求继续保留了 API 服务（模型名 `deepseek-v4-pro`），计费不变。日常调 API 只需要把模型名写成 `deepseek-flash` 就行。价格上依然是峰谷计费，空闲时段输入缓存命中 0.02 元 / 百万 token、未命中 1 元、输出 4 元，高峰时段（周一至周五 9:00 ~ 12:00 和 14:00 ~ 18:00）翻倍，所以把批量任务挪到晚上跑能直接省一半。我用 2 个项目做过它和 V4 Pro、GLM-5.3-Flash 的三方横评，速度和完成度都是明显进步。另外它原生支持 Responses API，可以直接接入 Codex，不需要任何协议转换（具体接入方法可以阅读本板块「Claude Code」目录中的《Claude Code 和 Codex 对接国内模型教程》）。
- 阿里通义千问最新的旗舰模型是 2026 年 8 月发布的 Qwen3.8-Max，总参数 2.4 万亿但单次推理只激活约 95B，支持 100 万 token 上下文，而且是全模态的，图像、视频、文档、文本都能作为输入。它重点提升了编程和办公场景下的长周期自主执行能力，第三方盲测榜单的综合排名仅次于 Claude，同时也支持 Claude Code、OpenClaw 等主流框架。通过阿里云百炼平台可以 API 调用（输入 12 元/百万 Tokens，输出 36 元/百万 Tokens）或 Token Plan 订阅使用，官方还开源了模型权重和更适合本地部署的 Qwen3.8-27B。不过要客观地说，从开发者的实际反馈来看，它的纯代码能力还略弱于 GLM 和 Kimi K3，优势更多体现在长上下文和智能体协作上。
- 智谱 GLM 是清华团队出品的模型，一直是全球开源模型综合排名的第一梯队。最新的旗舰是 2026 年 8 月发布的 **GLM-5.3**（7530 亿参数 MoE），在 CyberGym 安全漏洞发现这类专项上还拿过第一。同系列还有一个非常值得关注的 **GLM-5.3-Flash**，就是之前在 OpenRouter 上匿名爆火的那个「牛来」模型，320B 参数只激活 18B，是智谱首个原生多模态模型，MIT 协议开源，价格只有 Claude Opus 4.8 的四十分之一，综合智能指数却能跟 Opus 4.8 打平。它的定位是「日常好用的高性价比牛马模型」，我自己实测下来，大部分任务它都能胜任（可以阅读本教程模型动态板块中的《GLM-5.3-Flash 编程能力实测 - 3 个项目案例》和《GLM-5.3 三模型横评 - DeepSeek Harness 统一评测》）。
- 月之暗面 Kimi 在很早之前就支持超长上下文能力，在国产模型中独树一帜，特别适合处理大型项目的代码。最新的旗舰是 2026 年 7 月发布的 **Kimi K3**，2.8 万亿参数，1M 上下文，在 BrowseComp 联网搜索和长周期编程上都很强，缺点是标价偏贵（输入 20 元、输出 100 元 / 百万 token），不过缓存命中的输入只要 2 元，所以特别适合缓存命中率高的长文档场景。
- 腾讯混元 CodeBuddy 能够和腾讯云服务深度集成，原生对接 3000+ 云 API，有等保三级安全认证，适合企业使用，而且价格便宜。
- 百度文心一言有免费额度，而且和百度的生态（比如百度秒哒平台）深度集成，适合创意类小项目需要快速商业化的场景。
- 小米 MiMo 也是值得关注的新选手。2026 年 9 月 22 日发布了 MiMo-V2.6 系列，旗舰 MiMo-V2.6-Pro 是万亿参数的全模态推理模型，同时还有低成本的 V2.6-Flash，以及输出速度最高快 20 倍的 V2.6-Pro-Ultraspeed。V2.6-Pro 的 API 价格很低（每百万 token 输入约 0.44 美元、输出约 0.87 美元），第三方综合智能指数却跟 GLM-5.3 在同一档，性价比很突出。你可以通过 CC Switch 等工具便捷地切换到 MiMo 模型使用。



### 国产模型的优势和局限

国产模型最大的优势就是价格便宜，API 价格一般是国际模型的 1/10。而且对中文理解更准确，国内直接访问速度快，符合国内法规要求。

当然也有一些局限。在最复杂的任务上，顶尖能力还是比 Claude Opus 差一些，工具和插件支持也不如国际模型丰富。

不过对于预算有限的学生和个人开发者，主要做中文项目、不方便访问国际服务的用户，或者需要大量 API 调用的场景来说，国产模型是非常好的选择。像我的很多 AI 产品对接了 DeepSeek、通义千问（Qwen3.8-Max）或者 GLM，它们的 API 价格极低，也有各种免费额度和订阅方案足够日常学习使用了。

另外分享一个 2026 年下半年很明显的趋势：**原生多模态正在成为国产模型的标配**。GLM-5.3-Flash 和 DeepSeek V4.1 Flash 都是原生多模态的，这对 AI 编程来说意义很大 —— 模型能自己截图看效果，就不用你一轮轮人工看页面对不对了，长程任务的成功率会明显提升。所以选国产模型时，除了看价格，建议多留一眼「支不支持视觉」这一项。

而且我相信，国产模型是有机会超越国际模型的，我相信开源的力量！

## 八、如何选择合适的模型？

这么多模型，各有各的优势，我到底该选哪个呢？

其实选择模型主要看两个维度：你的预算和你的使用场景。



### 按预算选择

预算的多少直接决定了你能用什么工具。

如果你预算充足（每月 200 元以上），可以订阅 Cursor Premium（30 美元，第三方模型按用量另计）配合 Claude Sonnet 5 或 Opus 5.5 使用，这是目前体验比较好的组合。如果你更习惯 Codex，ChatGPT Plus（20 美元）搭配 GPT-6 Sol 的额度也很耐用。Claude 的代码质量高，特别适合做复杂项目和商业项目。如果你是重度 Claude Code 用户，推荐开通 Max 5x（100 美元/月）或 Max 20x（200 美元/月）订阅，获得更多用量和顶配模型的访问权限。

如果预算有限，那就充分利用免费资源。DeepSeek 的 API 按量计费价格低（空闲时段更便宜）+ 通义千问有免费额度和 Token Plan 订阅 + Gemini Flash 每天有免费额度，这些资源组合起来，完全够学习和做个人项目使用了。而且国产模型的 API 价格很便宜，即使付费，每月几十块也能用得很爽。



### 按场景选择

不同的开发场景，适合的模型也不一样。

1）学习阶段：如果你还在学习，主力用 DeepSeek V4.1 Flash 或通义千问（Qwen3.8-Max 通过 Token Plan 订阅很划算），辅助用 Gemini Flash 的免费额度。这个阶段重点是熟悉 AI 编程的感觉，这些模型完全够用。

2）做前端 / UI 项目：Claude Opus 5.5 目前是第一梯队里最能打的，我实测它做的 3D 场景和复刻 Cursor 界面都是最细腻的；Fable 5.1 和 GPT-6 Astra 的前端审美和产品设计能力也很强。Gemini 3 Pro 在前端 UI 设计和 3D 构建方面也有优势，但要注意 Flash 线的前端效果不如旗舰，实测下来 AI 味儿比较重。

3）做全栈项目：优先选择编程能力强的 Claude Sonnet 5 或 Opus 5.5，能力全面，前后端都能应对。配合 Cursor 使用，开发体验很好。如果需要快速生成完整项目，智谱 GLM-5.3 的速度和效果也不错。

4）处理大型代码库：Claude 全系（1M Token）、Gemini 3.8 Flash（1M Token）、DeepSeek V4.1 Flash（1M Token）和 Kimi K3（1M Token）都能一次性分析整个项目。但要注意 GPT-6 系列虽然有 105 万窗口，单次输入超过 27.2 万 token 会跳到更贵的长上下文费率。

5）快速迭代开发：DeepSeek V4.1 Flash 的输出速度很猛（实测 160 TOK/s 起，写代码时能到 287 TOK/s），首 token 只要 0.3 秒，特别适合需要快速验证想法的场景。GPT-6 Sol 在 Codex 里的交付速度也很快，同样的任务耗时不到 Opus 5.5 的三分之一。

6）需要 AI 自己验收前端效果：选原生多模态的模型，比如 DeepSeek V4.1 Flash、GLM-5.3-Flash，或者 Claude、GPT 全系。纯文本模型写完页面看不见自己的成果，只能瞎猜或者叫子 Agent 帮忙看，体验很割裂，成品质量也会掉一档。

7）大量测试和调用：DeepSeek 的 API 价格极低，而且通义千问（Qwen3.8-Max）也有 Token Plan 订阅方案，适合需要大量调用的场景，测试时可以放心使用。

8）需要 AI 操作没有 API 的软件：GPT-6 Astra 是目前最强的电脑操作模型。不过要有心理准备，我实测让它操作 KiCad 画 PCB 布线，看菜单点按钮都没问题，但精细的画布拖拽就不太行了。



### 个人选择

对我个人而言，因为有比较丰富的项目开发经验、做过不少商业项目。所以在选择模型时，我一般会优先考虑能力较强的大模型。日常开发主力用 Cursor + Claude Sonnet 5，这个组合功能全面、效果好。

其他情况：

- 遇到特别复杂的长程任务、或者视觉要求高的前端项目时，会切换到 Claude Opus 5.5。
- 需要 AI 帮我操作电脑时，用 GPT-6 Astra；日常在 Codex 里跑任务，用更省额度的 GPT-6 Sol。
- 需要追求速度和性价比时，会选择 GLM-5.3-Flash 或者 DeepSeek V4.1 Flash。
- 大量测试时用 DeepSeek 或者通义千问 API，因为相对便宜。而且 DeepSeek 的空闲时段单价只有高峰的一半，能挪到晚上跑的任务我都挪。
